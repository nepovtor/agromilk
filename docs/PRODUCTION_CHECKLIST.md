# Production checklist

## 1. Секреты и окружение

- [ ] `NODE_ENV=production`
- [ ] `APP_URL` и `APP_ORIGIN` указывают на HTTPS-домен
- [ ] в Netlify задан `API_PROXY_URL` с HTTPS-origin backend без `/api`
- [ ] `COOKIE_SECRET` содержит не менее 32 случайных символов
- [ ] установлен уникальный сложный `ADMIN_PASSWORD`
- [ ] `DATABASE_SSL=true`, если это требуется провайдером PostgreSQL
- [ ] секреты не сохранены в Git

## 2. Уведомления

- [ ] проверена отправка заявки по SMTP
- [ ] проверена отправка уведомления в Telegram
- [ ] адрес `MAIL_TO` принадлежит ответственному сотруднику
- [ ] ошибки внешних сервисов видны в логах

## 3. Контент

- [ ] проверены названия, составы и способы приготовления всех продуктов
- [ ] загружены актуальные сертификаты и паспорта качества
- [ ] указаны реальные контакты, адрес и режим работы
- [ ] проверены условия доставки, минимальная партия и скидки
- [ ] опубликованы необходимые инструкции

## 4. Право и безопасность

- [ ] политика конфиденциальности согласована с организацией
- [ ] определён срок хранения заявок
- [ ] проверены права доступа администраторов
- [ ] включено автоматическое обновление сертификата TLS
- [ ] настроены резервные копии PostgreSQL и uploads
- [ ] выполнено восстановление из тестовой резервной копии

## 5. Приёмочное тестирование

- [ ] desktop: Chrome, Firefox, Safari, Edge
- [ ] mobile: iOS Safari и Android Chrome
- [ ] форма заявки: успех, ошибки валидации, повторная отправка
- [ ] админ-панель: вход, выход, сессия, каталог, статьи, заявки
- [ ] проверены страницы `/`, `/instructions`, `/privacy`, `/admin/login`
- [ ] `/api/v1/health` открывается через публичный домен Netlify
- [ ] загруженное изображение открывается через `/uploads/*` после redeploy backend
- [ ] выполнены `make check`, `make test` и `pnpm audit --prod`
